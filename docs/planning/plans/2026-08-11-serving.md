# Serving Implementation Plan

**Goal:** Add a FastAPI service exposing `POST /predict/churn` and `GET /forecast/mrr?horizon=N`, backed by the two `@production`-aliased MLflow models, plus a Dockerfile/compose to run it.

**Architecture:** Two new pure functions (`CategoricalCastingModel.predict_proba`, `recursive_forecast`) carry all the logic with zero FastAPI/MLflow imports beyond what's already established; `serving/app.py` is a thin FastAPI wrapper that loads models at startup and calls into them.

**Tech Stack:** FastAPI, Uvicorn, Pydantic v2 (via FastAPI), `mlflow.pyfunc`, Docker/docker-compose, pytest + FastAPI `TestClient`.

## Global Constraints

- Endpoints: `POST /predict/churn`, `GET /forecast/mrr?horizon=N` (spec: Purpose)
- `horizon` validated `1–24`; 422 outside that range (spec: Decisions made this session, Error Handling)
- Churn request: 422 on bad payload shape/type via Pydantic (spec: Error Handling)
- 503 if a model isn't loaded (startup failure or still pending); also 503 if `forecast_features.parquet` is missing (spec: Error Handling)
- Model URIs: `models:/churn_model@production`, `models:/forecast_model@production` (spec: Decisions carried forward)
- Churn response: both `churn_probability` (float) and `churn_prediction` (bool, threshold 0.5) (spec: Decisions made this session)
- Models loaded once at startup, cached in `app.state`, not per-request (spec: Decisions made this session)
- Docker: bind-mount `mlflow.db`, `mlruns/`, `data/` — do not `COPY` them into the image (spec: Decisions made this session)
- Accessing custom methods (`predict_proba`) on a loaded pyfunc model requires `.unwrap_python_model()` (spec: Components §1)

## Prerequisite

None — real registered/promoted models (`churn_model` v2, `forecast_model` v3) and real `data/features/forecast_features.parquet` already exist locally from sub-projects 2-3, so this plan's final sanity check runs against real data directly.

```python
# src/churn_mlops/lib/recursive_forecast.py
from typing import Callable

import pandas as pd


def recursive_forecast(
    seed_df: pd.DataFrame, horizon: int, predict_fn: Callable[[pd.DataFrame], object]
) -> float:
    df = seed_df.copy().reset_index(drop=True)

    for _ in range(horizon):
        predictions = list(predict_fn(df))
        df["lag_3"] = df["lag_2"]
        df["lag_2"] = df["lag_1"]
        df["lag_1"] = predictions
        df["rolling_3mo_mean"] = df[["lag_1", "lag_2", "lag_3"]].mean(axis=1)

    return float(df["lag_1"].sum())
```

```python
# src/churn_mlops/serving/app.py
import logging
from contextlib import asynccontextmanager

import mlflow.pyfunc
import pandas as pd
from fastapi import FastAPI, HTTPException

from churn_mlops.lib.churn_model import FEATURE_COLUMNS as CHURN_FEATURE_COLUMNS
from churn_mlops.serving.schemas import ChurnPredictRequest, ChurnPredictResponse

logger = logging.getLogger(__name__)

CHURN_MODEL_URI = "models:/churn_model@production"
FORECAST_MODEL_URI = "models:/forecast_model@production"


@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.churn_model = None
    app.state.forecast_model = None

    try:
        loaded = mlflow.pyfunc.load_model(CHURN_MODEL_URI)
        app.state.churn_model = loaded.unwrap_python_model()
    except Exception:
        logger.warning("Failed to load churn_model@production", exc_info=True)

    try:
        loaded = mlflow.pyfunc.load_model(FORECAST_MODEL_URI)
        app.state.forecast_model = loaded.unwrap_python_model()
    except Exception:
        logger.warning("Failed to load forecast_model@production", exc_info=True)

    yield


app = FastAPI(lifespan=lifespan)


@app.post("/predict/churn", response_model=ChurnPredictResponse)
def predict_churn(request: ChurnPredictRequest):
    if app.state.churn_model is None:
        raise HTTPException(status_code=503, detail="churn_model not loaded")

    row = pd.DataFrame([request.model_dump()])[CHURN_FEATURE_COLUMNS]
    probability = float(app.state.churn_model.predict_proba(None, row)[0])

    return ChurnPredictResponse(
        churn_probability=probability,
        churn_prediction=probability >= 0.5,
    )
```

```python
# src/churn_mlops/serving/app.py — add these imports at the top
import pandas as pd
from fastapi import Query

from churn_mlops.lib.forecast_model import FEATURE_COLUMNS as FORECAST_FEATURE_COLUMNS
from churn_mlops.lib.recursive_forecast import recursive_forecast

# module-level constant, near the other URI constants
FORECAST_FEATURES_PATH = "data/features/forecast_features.parquet"


# add this route at the end of the file
@app.get("/forecast/mrr")
def forecast_mrr(horizon: int = Query(ge=1, le=24)):
    if app.state.forecast_model is None:
        raise HTTPException(status_code=503, detail="forecast_model not loaded")

    try:
        forecast_features = pd.read_parquet(FORECAST_FEATURES_PATH)
    except FileNotFoundError:
        raise HTTPException(status_code=503, detail="forecast_features data not available")

    seed_df = (
        forecast_features.sort_values("month")
        .groupby("customerID")
        .tail(1)
        .reset_index(drop=True)
    )

    def predict_fn(df: pd.DataFrame):
        return app.state.forecast_model.predict(None, df[FORECAST_FEATURE_COLUMNS])

    total = recursive_forecast(seed_df, horizon=horizon, predict_fn=predict_fn)

    return {"horizon": horizon, "forecast_total_mrr": total}
```

Note: `FORECAST_FEATURES_PATH` must be read via module attribute lookup at call time
(`pd.read_parquet(FORECAST_FEATURES_PATH)` inside the function body reads the module global
each call), not captured into a local/default-argument at import time — otherwise
`monkeypatch.setattr` in the tests won't take effect.
