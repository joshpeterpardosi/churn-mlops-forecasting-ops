HOW IT WORKS

01

Dagster trains

Assets pull the raw data, build features, and train both models on a schedule.

02

MLflow registers

Each run is logged and compared against the current production alias; better models get promoted.

03

FastAPI serves

This app loads the production alias at startup and answers every request on this page.
